# AGENTS

Guidance for AI coding agents working in `filagora-newsletters`. `CLAUDE.md` imports this file; edit here.

## What this is

A **placeholder**: the repository holds only a README. Newsletters, subscribers, sends and events (independent of any one mail provider) are planned for the Filagora family but nothing is built, scheduled or released. Part of Filagora, a family of MIT-licensed Laravel 13 / Filament 5 packages (forums, CMS, entitlements, logs, compliance, messages, search, push, memberships). Composer vendor `filagora`, namespace `Filagora\<Name>\`, default table prefix `filagora_`, commands `filagora:*`, env `FILAGORA_*`. Every package is pre-1.0 (`0.x`): the API may change between minor versions.

## Working here

- Do not scaffold code on your own initiative. Starting the package is the user's decision, and it begins from `filagora-package-skeleton` (follow its "Creating a package from this template" steps) after a design document exists in the private planning repository.
- Until then, keep the README accurate: it must keep saying "planned, not yet built".
- Public repository: no private hostnames, IP addresses or personal email addresses anywhere.
